An interactive visual **JSON Schema Builder & Form Generator** built with React, Vite, and Tailwind CSS. Allows developers and product teams to visually compose complex JSON schemas, define validations, and generate live interactive form previews in real-time.

---

## ✨ Features
- **Visual Schema Composer**: Add, edit, nest, and rearrange JSON object and array fields visually.
- **Type Support**: Strings, Numbers, Integers, Booleans, Arrays, and nested Objects.
- **Validation Rules**: Define required fields, minimum/maximum lengths, regex patterns, and default values.
- **Live JSON Preview**: Instant side-by-side synchronized view of the generated JSON Schema.
- **Export & Copy**: One-click JSON schema export and clipboard copying.

---

## 🚀 Getting Started
```bash
npm install
npm run dev
```
